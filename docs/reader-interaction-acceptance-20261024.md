# 阅读器交互与选区整段书摘修改验收

日期：2026-10-24。实施基线：`70d46a8`。依据：本轮用户三次截图与反馈，以及 `20261024-阅读器交互与AI书摘修改规划-v1.md`。本轮用户明确授权实施完成后推送远端。

## 完成行为

- 当前选区生成书摘：程序保留冻结选区全文及位置，AI仅提供整体解读，保存为一条；保留换行、空白、标点及字符簇。不依赖模型重新抄写，不按句拆分。超8000 UTF16单元或多个不连续span时在HTTP前拒绝；解读缺失/超4000时不保存。仍受用户配置输入上限限制。
- 当前页与全书页范围继续提取多候选，提示词优先完整叙述/对话，避免孤立语气词；每条仍须严格原文校验。此处是提取指引，不宣称所有真实模型响应都能保证语义完整。
- “分析所选范围”“解释选区”合并为“AI 解读”，两个动作均遵循同一范围。只有全书页范围显示起止页，切离清空；当前选区无选择时提示且不能执行，不回退整页。
- 目录、排版、AI面板独立折叠，释放对应列或行，开关和全屏入口常驻。状态在当前VM实例中保留，不跨进程保存。AI收起后顶部仍显示处理中与取消入口；结果/待保存批次不因折叠清除。
- 重排沿用稳定正文锚点，保留有效选区，清空过期页码；准备中任务遇重排取消，已提交请求沿用冻结快照，不重复发送。布局未就绪时禁止新发起AI任务。
- 结果区分部分成功、全部未通过原文核验、原文已存在与无候选；零新增时不宣称已保存原文。
- 沿用原子保存、去重、回跳、本地重试和安全撤销，不修改数据库schema，不自动修改历史碎片书摘。
