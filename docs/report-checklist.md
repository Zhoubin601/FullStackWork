## 交付前另行核验

- [x] 十个业务视图均已实现、可达、有实际功能，未用弹窗或空页面凑数。
- [x] 应用/业务库同参考语法树口径统计，达到最低 45 类、7 接口，记录相对开发目标 50 类、至少 10 接口的差异；不漏计默认访问级别类型。
- [x] ServiceLocator 真实持有 IoC 容器，从容器解析 VM，构造依赖自动注入；不是手工实例集合。
- [x] 全部服务与 VM 按示例单例注册；导航执行时经 Current 取得 VM，无反向构造注入；三类常量、主 VM 返回栈和反射视图缓存均可对应老师源码。
- [x] 八项架构要求均能指出对应实现和报告说明。
- [x] 页码统计、重读和当前进度在界面、代码、测试与报告中口径一致。
- [x] 源码包只包含 Code 内交付白名单文件；解压后可还原、构建、测试和启动。
- [x] 源码包大小不超过 10,000,000 字节，无编译结果和工作过程目录。
- [ ] 姓名、学号、班级已由用户提供并复核，截止日期已记录或明确资料未提供。
- [ ] 源码压缩包及 PDF 存在于 output，名称使用实际交付日期与版本。
