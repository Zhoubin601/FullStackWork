P32: 项目背景与意义
P33: 个人阅读中，书籍资料、阅读活动与摘录通常分散记录。阅记以本地离线应用统一管理这三类信息，并由阅读记录推导当前进度、计划状态和统计结果，使用户能够追踪阅读活动、整理感想及恢复自己的数据。
P34: 项目不提供电子书阅读器、账号登录、联网检索或云同步。其业务边界是“记录阅读”，用户录入的阅读记录表示自身活动声明，不能据此推断所有未记录页段均已读过。演示数据中的书名、作者、摘录和感想均明确标注为虚构资料。
P35: 1  需求分析
P36: 1.1  功能需求
P37: 应用实现录入书籍、制定计划、记录阅读、整理书摘和查看统计的完整闭环。十个独立业务页面及主要能力如下。
P38: 
P39: 初始化页、主窗口、主容器和阅读记录弹窗不用于补足十个业务页面。编辑未保存时，返回、切换菜单与关闭窗口共用保存、放弃、取消离开语义；保存失败保留草稿。列表返回刷新数据，保留当前搜索条件。
P40: 1.2  非功能需求
P41: 业务数据保存在用户本地应用数据目录，断网后核心业务可用。首次依赖还原需要NuGet来源；“运行离线”不等于“首次还原离线”。数据库写入串行，跨表修改采用事务。异步命令处理IO、忙碌状态和错误重试。
P42: 界面使用中文标签、侧边导航、统一表单及浅深主题。原生文件选择器使用系统语言，Linux历史测试中的GTK选择器部分文字为英文；Windows本机使用实际系统文件选择器。代码采用UI与Library职责分离，业务服务通过接口注入，便于替换依赖测试。本文不提供未经测量的性能指标，也不宣称已完成大规模数据压力测试。

P50: 2.2  功能模块设计
P51: 菜单提供概览、书库、书摘、计划、统计及设置六个入口。书库进入详情或书籍编辑；详情进入书籍编辑、书摘编辑、计划编辑及记录弹窗；书摘和计划列表进入相应编辑页。内容返回保留上一级业务上下文，菜单切换清空历史栈。左上角返回仅在当前模块有上一页时显示，模块首页隐藏入口；编辑页仍执行未保存确认与忙碌保护。
P52: 导航顺序为定位目标单例、SetParameter、切换内容或压栈、Loaded公开异步命令加载。加载失败保留目标页面，呈现错误及重试入口。重复同一单例内容目标在SetParameter之前拦截，避免覆盖栈中原参数；不同书籍经返回书库再打开，不构造同类型详情的多份历史快照。
P53: 2.3  数据/数据库设计
P54: 
P55: 图 2  实际四表实体关系；子表BookId外键级联删除
P56: Book含Id、Title、Author、Category、TotalPages、Description、CreatedAt和UpdatedAt。ReadingRecord含Id、BookId、ReadingDate、StartPage、EndPage和Minutes。Quote含Id、BookId、Text、Thoughts、可空Page、IsFavorite及创建/修改时间。ReadingPlan含Id、BookId、StartDate和TargetDate。数据库user_version为1，初始化事务创建表并启用外键。
P57: 记录约束为1 ≤ 起始页 ≤ 结束页 ≤ 总页数、分钟数为正整数、日期不晚于本地当天。当前页取最大结束页，无记录为0；累计页数对每条记录求闭区间长度之和，包含重读。完成日期为读至末页记录的最早日期。修改记录或总页数后由有效数据重新推导状态。
P58: 新建或编辑计划时，同一本书不能再关联第二个计划；普通新计划不能关联已完成书籍。旧备份中的多个完成计划可保留，但修改记录或总页数会使其同时变为未完成时，整个操作拒绝并提示先清理多余计划。未逾期的建议每日页数为剩余页数除以包含当天的剩余天数后向上取整；完成为0；逾期单列状态与剩余页数。删除计划不删除记录。

P74:     }
    public BookProgress Calculate(Book book, IEnumerable<ReadingRecord> records)
    {
        var all = records.Where(x => x.BookId == book.Id).ToArray();
        return new BookProgress
        {
            Book = book,
            CurrentPage = all.Select(x => x.EndPage).DefaultIfEmpty(0).Max(),
            TotalReadPages = all.Sum(x => (long)x.EndPage - x.StartPage + 1),
            TotalMinutes = all.Sum(x => (long)x.Minutes),
            CompletedOn = all.Where(x => x.EndPage == book.TotalPages).Select(x => (DateTime?)x.ReadingDate.Date).Min()
        };
    }

P115: 3.3  难点和解决方案
P116: 
P117: 本轮复核还发现加载与保存期间输入保护不足，以及计划状态变化与备份校验不一致。修复后，表单按字段合并未改值并保留用户修改，保存仅确认实际提交的快照；保存中新增修改保留在编辑页，新建成功回填主键避免重复插入。加载失败后可在编辑页重新加载。计划变更、记录修改与总页数修改在同一数据库事务中维护约束，拒绝不安全操作且不删除原数据。
P118: 后续修复还覆盖旧删除结果影响新导航、忙碌Loaded请求丢失、恢复期间导航，以及收藏与恢复交错。删除使用固定目标及参数版本检查；加载等待前次操作；所有页面忙碌时禁止菜单、返回、关闭和直接内容跳转。收藏由存储在同一事务内仅更新收藏位及时间，避免旧实体整体回写覆盖恢复数据。上述回归已纳入当前94项测试。本版另修复栈底仍显示无效返回入口的问题：CanGoBack从主VM现有栈派生，集合变化同步按钮可见性和命令可执行状态；新增真实MainView绑定回归，保留菜单清栈与内容逐级返回。
P119: 重复目标拦截、参数版本、草稿保护、串行写入和事务均为阅记新增业务正确性措施。参考README明确未解决线程与原子性，不能把这些新增设计称为参考项目原有机制。
