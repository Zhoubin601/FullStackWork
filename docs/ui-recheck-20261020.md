# 最新版本真实 UI 复核

日期：2026-10-20；版本：`0313917`。本轮从零启动隔离业务库，实际运行当前 Release 程序并操作 X11 窗口。未修改应用代码、参考源码、原始资料或交付物。依据为当前 Code/Views、命令实现和运行结果，旧截图仅用于了解操作方法。

## 结论

正常主流程已实际打通：空库自动初始化 → 新建书籍 → 详情 → 阅读记录 → 收藏书摘 → 阅读计划 → 概览/统计 → 原生 GTK 选择器导出 → 书籍级联删除 → 原生选择器恢复 → 再次启动。10 个业务页面全部实际到达。两次运行绑定诊断均为 0。

这是正常操作路径的结论，不覆盖并发恢复等业务边界；本轮独立业务审查发现的问题另见 business-recheck-20261020.md，不能由 UI 主流程通过推导全部功能无缺陷。

Debian 13 / Linux x64，.NET 8.0.424，Xvfb `:119`、1280×960。Xvfb/xdotool 在允许 Debian 软件源下载后于用户目录解包。数据位于 `/workspace/scratch/recheck-ui/data`，未使用用户日常数据库。无窗口管理器，Alt+F4未退出，随后仅向隔离应用进程发送SIGTERM并再次启动；本轮证明数据持久化，不声称已验证窗口关闭事件。
