项目背景与意义 
个人阅读中，书籍资料、阅读活动与摘录通常分散记录。阅记以本地桌面应用统一管理这些信
息，使用户能够阅读电子书、追踪阅读活动、整理感想并恢复自己的数据。项目在原有阅读与书摘管
理基础上，加入 TXT/EPUB 原生阅读器及 DeepSeek AI 阅读辅助，形成“导入—阅读—摘录—计划
—统计—备份”的业务闭环。 
系统同时服务两类阅读方式：纸质书等手动书籍以真实页码和分钟数记录活动；电子书以稳定正
文位置、百分比和自动阅读会话记录活动。动态排版页号仅服务当前阅读界面，不作为纸质页数计入
统计。AI 仅处理用户主动确认的正文范围，本地阅读和手动书摘不依赖网络。 
1  需求分析 
1.1  功能需求 
模块 主要功能与业务结果 
书籍管理 手动录入、编辑、搜索、状态筛选及分页；TXT/EPUB 多选导入、收件区扫描、摘要去重及受管
副本删除。 
原生阅读 章节目录、分页翻阅、键盘操作、F11 全屏；字体搜索与预览、字号和纸张配色；三面板独立收
起。 
进度与会话 按正文锚点续读；首屏实际呈现后启动会话，正常离开时保存时长与最后位置；完成标记与回看
位置分离。 
书摘与收藏 手动书摘及原生选区保存；Ctrl+C / Ctrl+S；去重、感想、收藏、编辑、删除和精确原文回跳。 
AI 阅读辅助 当前页、选区和全书页范围解读；生成并自动保存通过核验的书摘；去重、本地保存重试及批次
撤销。 
计划与统计 制定目标日期并呈现计划状态；手动页数与两类阅读时长分别统计，电子书不生成虚假物理页
数。 
设置与数据 浅深主题、真实 AI 配置与会话凭据；完整 ZIP 备份恢复、旧 JSON 兼容恢复及异常操作日志
恢复。

1.2  非功能需求 
离线能力与可维护性 
业务数据保存在当前用户本地应用数据目录。断网后可阅读已有书籍、保存手动书摘、查看计划
与统计；只有用户主动确认的 AI 操作联网。首次依赖还原需要 NuGet 来源或完整缓存，不能把“日
常阅读离线”理解为“首次构建无需联网”。工程保留 UI、Library 与 UnitTest 的职责划分，业务通过
接口注入，以便替换平台能力和隔离测试。 
一致性与可靠性 
数据库访问串行，跨表写入采用事务；文件系统与数据库的组合操作采用 staging、trash 与持久
化操作日志恢复。书籍使用不可变 BookUid，正文使用 DocumentKey 标识版本，维护操作更新 
DataEpoch，防止旧页面或迟到响应写入新数据。恢复先完整校验并生成原库自动备份，成功后再替
换数据。原始导入文件保持不变。 
交互与响应 
界面使用中文标签、六项侧边菜单、统一表单和浅深主题。文件选择使用系统原生对话框。正文
重排保留稳定位置和仍有效的选区；耗时任务提供忙碌、错误和取消反馈。以异步命令与可取消后台
索引减少界面阻塞；性能结论限于实际测试样本，具体采样口径见第 4 章。 
AI 数据与费用边界 
请求前需保存上传知情确认，并再次确认所选范围及可能费用。会话 Key 只在进程内存保存，
不写普通配置、源码、日志或备份；退出后须重新输入。请求默认输入上限 24000 个 UTF-16 单
元、输出 2048 token、超时 45 秒；输入硬上限 60000 个 UTF-16 单元，页范围最多 200 页和 
2048 个片段。字符单元、token 和真实费用是不同概念，费用以供应商账单为准。 
要求 系统处理 
请求控制 无凭据或未同意上传时在 HTTP 前拒绝；超时、取消或错误不自动重新计费请求。 
原文可信度 AI 候选须在已冻结的连续原文中逐字匹配并唯一定位；通过原文核验不代表 AI 解读正确。 
范围限制 无账号登录、云同步与在线书源；不支持 PDF/OCR、DRM 或固定版式 EPUB。 
平台边界 已实测 Windows 11 x64、150% 缩放；其他缩放、跨屏和商业 EPUB 未扩大验收。

2.2  功能模块设计 
概览、书库、书摘、计划、统计及设置构成六个菜单入口。书库进入书籍详情、编辑或 
ReaderView；详情关联阅读历史、计划和书摘；书摘可回到电子书的原文位置。编辑未保存时统一提
供保存、放弃、取消；活动阅读器正常离开前须结束会话。左上角返回仅在存在上一级内容时显示。 
运行期导航通过 NavigateToAsync 等待 MainViewModel.RequestNavigationAsync。同书原文回跳
在现有 Reader 实例内执行；跨书、返回、菜单及关窗经统一离开编排，先取消或结束关联动作，再
提交会话和切换内容。提交失败保留重试或继续阅读入口，避免页面已离开而会话未保存。

数据职责与关键约束 
表/数据 关键字段与规则 
Book Id 主键，BookUid 唯一且不可变，Kind 区分手动与电子书；手动 TotalPages > 0，电子书 
TotalPages = 0。 
ReadingRecord BookId 外键，仅用于手动书；起止页合法、分钟数为正，结束页不得超过总页数。 
Quote / ReadingPlan 书摘保留 Text、Thoughts、收藏及 Revision；电子书书摘 Page 必须为空。计划关联书籍
与起止日期。 
EbookFile BookId 一对一；FileId、来源/正文 SHA256、受管相对路径、ParserVersion 与 
Ready/Missing/Invalid 状态。 
EbookProgress 最后正文位置、CurrentPercent、HasStarted 与独立完成时间；重新打开恢复最后位置而非
历史最高页。 
EbookReadingSession SessionId 主键；书籍/正文身份、起止位置、UTC 时刻与时区偏移、时长、关闭日及时钟
异常标记。 
QuoteOrigin QuoteId 一对一；来源类型、原文与起止位置、上下文摘要、定位状态、可空批次关联和
唯一去重键。 
AiGenerationBatch 不可变批次回执含 ScopeSha256、插入 ID 清单、插入/重复/拒绝计数及可撤销状态。 
AiGenerationBatchItem BatchId + QuoteId 复合主键；生成时 Revision 与内容摘要用于判断撤销时是否仍可删
除。 
 
手动进度取有效记录的最大结束页，累计页数对每条闭区间长度求和并包含重读；电子书只统计
正文百分比及会话时长。总时长先累加毫秒再换算，避免逐会话取整误差。完成标记与回看进度分
离，重置仅清除当前进度和完成标记，保留历史与书摘；多个历史计划可能同时被重置为未完成时，
整次操作拒绝。 
迁移在事务内为旧书生成 BookUid，新增 Kind、Quote.Revision、业务表、索引和触发器；检查 
integrity_check 和 foreign_key_check 后才写 user_version=2。旧字段不清空。触发器保护书籍身份、
书籍类型、电子书零物理页数及批次回执不可变性，服务层仍承担完整业务校验。

2.4  接口与类设计 
应用 UI 与 Library 包含 137 个类、41 个接口、134 个 C# 源文件和 15 个视图文件。按工
程、命名空间及完整类型名合并 partial 声明，统计手写 class 和 interface，不计入测试工程、自动
生成代码、record、struct 和 enum。 
课程参考项目 DailyPoetryA 包含 63 个类、10 个接口和 9 个视图。按类与接口数量不少于参
考项目 70%、视图数量不少于参考项目的要求，本项目达到相应规模。15 个视图文件包括窗口、初
始化、容器和记录弹窗，其中业务页面为 11 个。 
接口分组 职责与代表接口 
基础存储与业务 IDatabaseService、IBookStorage、IQuoteStorage、IReadingService、IStatisticsService 等承担
串行数据访问、事务和规则投影。 
导航与平台 IRootNavigationService、IMenuNavigationService、IContentNavigationService；
IFileService、IReaderPlatformService 等封装系统交互。 
电子书导入 IEbookLibraryService、IBookParser，负责扫描/导入、TXT/EPUB 解析和删除协调；多个解
析器按格式选择。 
正文与排版 IReaderDocumentService 返回规范化正文与锚点；IReaderLayoutService 负责当前视口分
页；IReaderFontCatalog 枚举本机字体。 
阅读状态与摘录 IReaderSessionService、IReadingHistoryService、IReadingStateCalculator、
IReaderQuoteService 统一会话、混合历史与原文定位。 
AI 与凭据 IDeepSeekClient、IReaderAiService、IAiQuoteVerifier、IAiSettingsStorage、ISecretStore 分
离请求、工作流、核验、配置与会话秘密。 
数据维护与恢复 IApplicationDataCoordinator、ICompleteBackupService、IOperationRecoveryService 等管理
租约、数据代际、完整恢复和失效清理。 
 
ReaderOpenIdentity 同时携带 BookId、BookUid、DocumentKey、DataEpoch、ReaderInstanceId 
和参数版本。整数 ID 可重用，不能单独作为异步写入依据；身份和租约均验证成功才允许提交。关
键接口中的 CancellationToken 明确传播取消，数据契约使用 record 表示快照，但这些 record 不计
入上述类数。

3.3  难点和解决方案 
实际问题 处理与验证 
动态页号无法用于长期定位 规范化正文配合 DocumentKey 、章节和 UTF-16 锚点；图片使用非文本块锚点。重排后
解析新页，永久回归与实际重启/回跳验证。 
手动页数与电子书进度冲突 Kind 区分书籍；电子书 TotalPages 为 0 且不生成手动页记录；统一状态计算器汇合时
长、计划与完成状态。 
缺失字体阻断排版 打开时采用临时可用字体并保留原偏好，点击应用才保存。测试确认缺失字体时仍可改字
号，手动错误字体被拒绝，默认字体可恢复。 
首屏重排取消导致会话不激活 呈现前先进入 Presenting；视口替代取消不标成 OpenFailed；仅实际绘制启动会话。可控
取消回归和真实窗口均验证只保存一条会话。 
AI 书摘改写、碎片化或重复 整段选区原文由程序保留；其他候选逐字连续匹配及消歧；数据库去重、原文回跳和撤销
形成闭环。 
迟到响应与数据恢复交错 请求冻结快照，响应后重验身份、会话和 DataEpoch；事务写入再次校验，旧响应不能写
入已恢复或已重置的数据。 
文件替换与数据库无法共用事
务 
通过 staging/trash、持久化阶段日志与数据库恢复标记编排；实际进程中断后启动对账，
不清空坏日志掩盖失败。 
 
AI 本地落库失败与远端生成失败分开处理：前者保留当前会话内有界待保存批次，以同一回执
重试；后者明确显示错误，不自动重发。事务回滚和提交确认丢失均有回归，避免重复收费或重复插
入。 
已知能力边界包括复杂 CSS、固定版式、DRM、非 UTF-8 XML、SVG/公式/音视频等不支持或
明确降级内容。长选区跨章节、跨图片或超过限额时要求缩小范围，不自动改写成不可验证的摘录。

性能测量与范围说明 
性能测试运行于 Windows、.NET 8.0.30 和 32 逻辑处理器环境。使用生产 ReaderViewModel 与
ReaderSurface 进行 Skia 离屏绘制，视口为 760× 440 DIP、输出 1140× 660像素。测量区分冷导入、预
热打开、翻页和重排，不将离屏采样等同于物理显示缩放测试。 
指标 测量结果 解释 
百万字符冷导入 约 2120.64 ms 解析/复制导入成本，独立于后续打开与首绘。 
预热打开 + 离屏首绘 约 465.10 ms 已做路由预热，OS/磁盘/字体缓存已热；非全新环
境冷启动首屏。 
200 次翻页 P95 约 6.68 ms 同一组测试的翻页耗时分布；不外推所有设备。 
20 次重排 P95 约 129.87 ms 同一组测试中字号/布局变更采样。 
布局调度最大间隔 约 43.21 ms UI Dispatcher 心跳，不等同于物理键鼠输入延迟。 
20 次切书后引用 文档/布局/解码图片均 0 生命周期引用清理结果，不等价于操作系统内存立
即归零。 
 
冷导入与预热首绘分别反映解析导入和缓存预热后的打开成本，不合并为同一首屏耗时。P95 描
述本组有限样本的分布，结果会受设备、书籍、字体和缓存状态影响。

5  总结与展望 
阅记已从阅读活动管理扩展为原生 TXT/EPUB 阅读与 AI 辅助应用，保留手动书籍、阅读记
录、书摘收藏、计划和统计等原有功能。通过真实 DI、三层导航和 UI/Library 分层，将原生排版与
平台操作连接到可测试的业务核心；通过稳定正文锚点、幂等会话、逐字原文核验和完整 ZIP 恢
复，使新增阅读能力与原有数据闭环衔接。 
源码包在独立目录中完成锁定依赖还原、Release 构建和自动化测试。353 项测试中 351 项通过、
0 项失败、2 项因符号链接权限跳过。界面测试覆盖主要阅读流程，备份恢复后 10 张业务表与 12 个
受管文件一致，支持系统在已测试环境中的可用性。 
系统实现的重点是保持数据语义与界面状态一致：手动页码和电子书百分比分开计算，阅读器通
过稳定正文锚点适应重排；统一导航在切换页面前结束活动会话，事务与操作日志共同处理数据库和
文件恢复。AI 仅处理用户确认的范围，原文核验和本地重试降低了错误摘录及重复请求的风险。 
后续优先补充 Windows 100%/200% 与跨屏实测、具备权限环境下的符号链接用例和授权商业 
EPUB 样本，再逐步扩大复杂排版兼容及大书库压力测试。AI 方面继续改善解读可读性与拒绝原因
提示，保持原文可验证、范围明确及本地保存重试不重复请求的边界。账号、同步与在线书源不在当
前实现范围。
