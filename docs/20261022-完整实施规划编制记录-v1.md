## 统一设计决定

- Windows x64 为首个发布验收平台；其他平台单独验收，不把跨平台框架当成跨平台已通过。
- 保持原生阅读器方向，只有实验失败且需改变方向时才讨论替代方案。
- 新数据库 schema=2，新完整备份 manifest=2；旧 JSON 格式 1 继续导入，恢复仍为整体替换。
- 固定默认书库、源文件不可变；收件文件只复制不移动；稳定正文版本随备份保存。
- 手动书籍与电子书共用 Book，电子书使用独立会话/位置；兼容读模型统一呈现。
- 续读位置可回退，电子书完成标记保持，只有显式重置才清除。
- 运行期文件系统与 SQLite 使用日志与补偿，不声称拥有跨资源原子事务。
- 真实 API 集成前先完成 Mock；需要用户在应用安全输入 Key 时通知，文档和聊天不收集密钥。
